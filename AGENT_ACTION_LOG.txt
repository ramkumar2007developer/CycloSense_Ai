Audit findings on per-input signals:
1. image_probability: Produced by ImageBaselineCNN head (downgraded to feature extractor per ADR-007,
   retains raw visual probability output for per-input inspection).
2. numerical_probability: Produced by NumericalMLP on 12 validated atmospheric features.
3. fusion_probability: Produced by multimodal FusionModel on joint visual and numerical embeddings.
4. Gate trigger: ALL signals >= gate_threshold (default 0.50). Evaluates per-sample probabilities,
   never training/eval metrics.

Decision Policy:
1. All signals >= 0.50 AND LLM says cyclone_consistent AND conf >= 0.70 -> VERIFIED_CYCLONE
2. All signals >= 0.50 BUT LLM says non_cyclone_consistent -> SECONDARY_REVIEW_CONFLICT
3. All signals >= 0.50 AND (LLM says uncertain OR conf < 0.70 OR human review flagged) -> HUMAN_REVIEW_REQUIRED
4. Any signal < 0.50 -> LLM_NOT_REQUIRED (normal ML result returned, verifier not called)
5. Gate activated but LLM error/timeout -> LLM_VERIFICATION_FAILED (preserves ML outputs, no crash)
